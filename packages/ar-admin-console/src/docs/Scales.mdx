# Scales

Every size, space, height and layer the console uses, defined in `src/lib/ui/tokens/tokens.css`.
The rules for using them are in **Design rules** (Spacing, Typography, Controls and icons,
Layers and shadows). None of these is themable: a theme changes the look, never the layout.
Samples use the current theme's fonts.

## Weights and line heights

Four actual weights and three line heights. Role aliases keep the intent clear without
introducing another visual tier.

| Token                      | Value | Use                                                 |
| -------------------------- | ----- | --------------------------------------------------- |
| `--fw-regular`             | 400   | text                                                |
| `--fw-medium`, `--fw-name` | 500   | leading text, names, options and button labels      |
| `--fw-semibold`            | 600   | field labels, box titles, table heads, current item |
| `--fw-bold`                | 700   | upper-case overlines and counts                     |
| `--lh-tight`               | 1.25  | titles and names that may wrap in a small box       |
| `--lh-snug`, `--lh-body`   | 1.5   | captions, tips and running text                     |
| `--lh-relaxed`             | 1.7   | longer prose such as dialog bodies and notes        |

## Spacing

All pages share one 1100px maximum content width (`--page-w`). The frame is start-aligned
and shrinks with the viewport; tables scroll within it if their columns need more room.

Layout spacing uses 8, 12, 16, 24, 32 and 48px. Component details such as an icon-to-label
gap can use smaller local values. Where three values are given, they apply at desktop,
≤1024px and ≤640px; two values mean desktop and ≤640px.

| Token                   | Value           | Between / inside                            |
| ----------------------- | --------------- | ------------------------------------------- |
| `--space-page-x`        | 32 / 24 / 16px  | page sides (desktop / ≤1024px / ≤640px)     |
| `--space-page-top`      | 24 / 24 / 16px  | above the page header                       |
| `--space-page-bottom`   | 48 / 48 / 32px  | below the last box                          |
| `--space-page-header`   | 8px             | extra after the page's 16px gap; 24px total |
| `--space-section`       | 16px            | boxes stacked on a page, panes side by side |
| `--space-grid`          | 12px            | tiles of one set                            |
| `--space-columns`       | 24px            | form columns inside a box                   |
| `--space-field`         | 16px            | fields and settings one below the other     |
| `--space-related`       | 8px             | a control and what belongs to it            |
| `--box-pad`             | 16 / 12px       | box sides; top and bottom of a box body     |
| `--box-head-pad-y`      | 12px            | box header, setting rows, danger rows       |
| `--box-foot-pad-y`      | 12 / 8px        | box footer                                  |
| `--note-pad-y` / `-x`   | 8·12 / 8·8px    | a note inside a box                         |
| `--tile-pad`            | 12px            | item card                                   |
| `--dialog-pad-y` / `-x` | 24·24 / 16·16px | dialogs                                     |

| Field            | label 13px semibold, control 14px               | hint, error and counter 12px                                         |
| Table            | head 12px semibold, cell 13px, second line 12px | sort icon 12px                                                       |
| Badge            | 12px semibold; count 12px bold                  | status dot 6px                                                       |
| Selected chip    | label 13px                                      | 28px high; remove target 24px with a 12px icon                       |

| Icon-only action | —                                               | 18px icon / 32px target; small 14px icon / 24px target               |

The use rules, including when to show help and how it is placed, are in **Design rules**.

## Layers

Lowest first. Dialogs, the drawer, tips and select menus are in the browser's top layer,
above all of these.

| Token           | Value | What                                 |
| --------------- | ----- | ------------------------------------ |
| `--z-nav`       | 30    | the sticky top nav                   |
| `--z-header`    | 40    | the sticky header                    |
| `--z-save-bar`  | 45    | the floating save bar                |
| `--z-menu`      | 60    | dropdown panels anchored in the page |
| `--z-toast`     | 70    | notifications                        |
| `--z-skip-link` | 100   | "skip to content" when focused       |
